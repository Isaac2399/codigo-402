## Pagos de empresas a proveedores

Este proceso lee las ventas de Secrets Pay y, cuando la empresa confirma una compra ya entregada, paga al proveedor en USDC de testnet.

En Secrets Pay, `SETTLEMENT_API_KEY` abre `GET/POST /api/events/settlement`. Aquí la misma clave va en `SECRETS_PAY_KEY`. El panel está en `http://localhost:3001/panel` (`npm run api`).
